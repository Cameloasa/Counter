# Counter App

A simple, responsive counter application built with **HTML, CSS, Bootstrap 5, and JavaScript**.

The app allows users to increase, decrease, and reset a numerical counter through an intuitive interface.

## Features

- **Increment:** Increase the counter by one.
- **Decrement:** Decrease the counter by one.
- **Reset:** Return the counter to zero.
- **Responsive design:** A clean interface that adapts to smaller screens.
- **Accessible controls:** Semantic HTML, descriptive button labels, and a live region for announcing counter updates.
- **Custom styling:** A dark theme with cyan accents, responsive typography, and interactive button states.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript (Vanilla JS)

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.

Bootstrap is loaded through a CDN, so an internet connection is required for its styles to load.

## How to Use

1. Click **+** to increase the counter.
2. Click **−** to decrease the counter.
3. Click **Reset** to return the counter to zero.

The counter starts at zero each time the page is loaded.
